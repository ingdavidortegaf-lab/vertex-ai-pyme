# 1 · Pantallas (lo que ve el tendero)

Cada archivo es una pantalla hecha con **Flutter** (lenguaje **Dart**). Las pantallas no se conectan a internet: le piden los datos a la base del celular (`../data/local_db.dart`).

- `home_page.dart`: la estructura con las 5 pestañas.
- `ventas_page.dart`: la caja.
- `inventario_page.dart`: productos y servicios.
- `oficina_page.dart`: informes, cartera y documentos.
- `registro_negocio_page.dart`: las preguntas del inicio.

Explicación completa: `docs/exposicion/1_pantallas.md`
